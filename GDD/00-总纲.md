# Mars Genesis：火星生态文明 · GDD 总纲 V0.2

> 副标题：从一艘星舰到一颗星球文明。
> 玩家身份：**MARS CORE AI** —— 火星建设总控制 AI。
> 设计主线：荒漠 → 基地 → 工业区 → 生态区 → 城市 → 文明。

核心理念来源：Starship 运输体系、ISRU 原位资源利用、火星土壤 3D 打印、自动化机器人建设、AI 城市管理、火星生态改造。

> **项目宪法**：《00-运行模型.md》——火星文明运行模型。定义八大子系统（能源/物流/水/氧/食物/工业/人口社会/生态）的因果关系、反馈环、瓶颈定律与不变量。任何建筑、科技、事件、AI 建议必须能从模型推导。
>
> **项目性质**：基于现实科学的火星文明仿真平台，不是传统娱乐游戏。目标是发现火星长期生存所需的条件、资源、技术与社会结构。

## 九大纪元

| 纪元 | 名称 | 核心玩法 |
|---|---|---|
| 一 | 无人建设时代 | 20 艘星舰抵达；MARS CORE AI 调度机器人；扫水冰、建太阳能阵列、着陆场、激光 3D 打印 |
| 二 | 基础工业时代 | 火星土采集→激光烧结→建筑模块；第一套科技树（生存科技 + ISRU 科技） |
| 三 | 自动工业时代 | 自动采矿、自动运输（物流网络）、自动制造 |
| 四 | 殖民时代 | 第一批人类抵达；居民系统上线（职业/技能/教育/健康/幸福/信仰/社交） |
| 五 | 生态循环时代 | 闭环生态（人→废弃物→肥料→植物→人）；动物系统；微生态（藻类/细菌/微生物） |
| 六 | 生态社区 | 人口 100–5000；学校/医院/超市/体育馆/公园 |
| 七 | 火星生态城 | 人口 10000+；居住/商业/工业/农业/科研/太空港分区 |
| 八 | AI 文明 | 量子计算中心、超级 AI 核心、机器人社会 |
| 九 | 火星改造 | 温室气体→人工磁场→海洋→森林→生态圈；地图 红→绿→蓝；终局 |

## 写作与生产约定

- GDD 每卷独立成文，版本号递增；每卷末尾必须有「MVP 子集」一节。
- DATA 的 schema 一次设计到位、支撑全量规模；**内容按 MVP 子集分批填充**（条目标记 `"mvp": true` 的先实现）。
- 数值只在 DATA 里定义，GDD 卷引用资源/建筑名时不许自创 ID。
- 写一卷、实现一包，不许"写完再开工"。
- 给 Muse/协作者生成内容时，必须遵守 `DATA/README.md` 第 7 节规范，提交前跑校验。
