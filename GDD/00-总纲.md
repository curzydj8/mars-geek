# Mars Civilization Simulator（火星文明模拟器）· GDD 总纲 V0.3

> 玩家身份：**MARS CORE AI** —— 火星建设总控制 AI。
> 一句话：从一艘星舰到一颗星球文明。

## 项目性质

基于现实科学的**火星文明仿真平台**，不是传统娱乐游戏。更接近：文明实验室、火星数字孪生、生存模拟器。

**核心循环**（取代"收集→升级→胜利"）：

```
发现问题 → 分析问题 → 设计方案 → 验证方案 → 发现新问题
```

最终目的不是通关，而是帮助发现火星长期生存所需的条件、资源、技术与社会结构，以及可能遇到的问题和解决方案。

> **项目宪法**：《00-运行模型.md》——火星文明运行模型。任何建筑、科技、事件、AI 建议必须能从模型推导；推导不出来的，不许进 DATA。

## 六层文明架构

所有系统统一归入六层（对应运行模型 §2）：

| 层 | 名称 | 内容 | 数据 |
|---|---|---|---|
| 一 | 自然层 | 温度/气压/辐射/重力/沙尘暴/地质/水冰分布。**玩家无法控制，只能适应。** | planets.json |
| 二 | 资源层 | 基础（氧/水/食物/电/热量）→ 工业（铁/铝/铜/硅）→ 高级（芯片/机器人/AI核心） | resources.json |
| 三 | 工业层 | Factorio 式：采矿→运输→冶炼→制造；无人车/轨道车/管道/无人机。**物流是文明命脉。** | buildings.json logistics.json |
| 四 | 生态层 | ONI 式三循环：水循环、氧循环、有机循环 | buildings.json animals.json |
| 五 | 社会层 | RimWorld 式居民（年龄/职业/教育/技能/健康/幸福）→ 家庭/学校/企业/社区/政府；犯罪/失业/心理/贫富差距都会出现 | citizens.json events.json |
| 六 | 文明层 | Cities: Skylines 式分区（居住/商业/工业/科研/农业）；基地→社区→小镇→城市→文明 | buildings.json（city/wonder 类） |

## 最大创新：先机器人，后人类

所有竞品几乎都是：人先来 → 开始建设。
本项目：**星舰 → 机器人 → 能源系统 → 工业系统 → 生态系统 → 人类**。
这更符合现实火星开发逻辑（先无人建设、后载人登陆）。

## 九大纪元

| 纪元 | 名称 | 核心玩法 |
|---|---|---|
| 一 | 无人建设时代 | 20 艘星舰抵达；MARS CORE AI 调度机器人；扫水冰、太阳能阵列、着陆场、激光 3D 打印 |
| 二 | 基础工业时代 | 火星土→激光烧结→建筑模块；第一套科技树（生存+ISRU） |
| 三 | 自动工业时代 | 自动采矿、自动运输（物流网络）、自动制造 |
| 四 | 殖民时代 | 第一批人类抵达；居民系统上线 |
| 五 | 生态循环时代 | 闭环生态；动物系统；微生态（藻类/细菌/微生物） |
| 六 | 生态社区 | 人口 100–5000；学校/医院/超市/体育馆/公园 |
| 七 | 火星生态城 | 人口 10000+；六区分区；太空港 |
| 八 | AI 文明 | 量子计算中心、超级 AI 核心、机器人社会 |
| 九 | 火星改造 | 五代路线见下；地图 红→绿→蓝；终局 |

## 终局：五代地球化

1. 封闭基地 → 2. 生态穹顶 → 3. 区域生态圈 → 4. 开放生态圈 → 5. 火星地球化（人工磁场/大气制造/海洋/森林/河流）。
终局不是"建成城市结束"，而是**不依赖地球补给、独立生长的火星生态文明**。

## 写作与生产约定

- GDD 每卷独立成文，版本号递增；每卷末尾必须有「MVP 子集」一节。
- DATA 的 schema 一次设计到位、支撑全量规模；**内容按 MVP 子集分批填充**（条目标记 `"mvp": true` 的先实现）。
- 数值只在 DATA 里定义，GDD 卷引用资源/建筑名时不许自创 ID。
- 写一卷、实现一包，不许"写完再开工"。
- 给 Muse/协作者生成内容时，必须遵守 `DATA/README.md` 第 7 节规范，提交前跑校验。
