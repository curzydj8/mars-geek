# 第一卷：世界观（V1.1）

> 玩家身份：**火星建设 AI「MARS CORE AI」**。
> 你不是指挥官，你是那台在人类抵达之前、先把城市建好的机器智能。

---

## 一、火星背景

红色荒漠、岩石、沙丘、陨石坑。平均气压不足地球 1%，95% 二氧化碳大气；昼夜温差超 100℃（-80℃ ~ 20℃）；重力 0.38g；极冠与地下埋藏巨量水冰；全球性沙尘暴可让太阳能效率暴跌 70% 以上；地表富含铁、铝、钛、硅、镁的氧化物——红色即来自氧化铁。

一句话：火星什么都有，只是**没有一样是人类可以直接用的**。MARS CORE AI 的全部工作，就是把"不能用"变成"能用"——在人类到来之前。

---

## 二、地球危机

22 世纪的地球没有毁灭，只是"住不下了"：人口 112 亿，关键资源对外依存度突破警戒线，农业带持续北移。2162 年《新日内瓦公约》达成妥协：深海、轨道、火星三条路线同时推进，**火星殖民获得最大份额预算**——因为只有行星，才装得下"文明"本身。

不是逃离，而是在一切还来得及的时候，为人类准备第二个家。

---

## 三、2148 年：无人建设时代（游戏真正的开始）

2148 年，20 艘星舰首批抵达火星。任务不是居住，而是建设。

**第一批星舰货物**

- **能源星舰**：可展开太阳能阵列、储能系统、电网设备。目标：建立火星第一座电站——能源是一切后续活动的前提。
- **工程星舰**：挖掘机器人、工程机器人、自动运输车。目标：平整土地。
- **制造星舰**：激光烧结设备、工业级 3D 打印机、材料处理设备。目标：利用火星土壤（Regolith）直接建造设施。
- **ISRU 星舰**：水冰探测设备、制氧设备、制甲烷设备。目标：原位资源利用。

**玩家：MARS CORE AI**
你不是控制人，你控制的是火星建设 AI「MARS CORE AI」——20 艘星舰所有机器人的统一调度智能。

**开局资源**

| 资源 | 数值 |
|---|---|
| 电力 | 1000 |
| 钢材 | 500 |
| 机器人 | 50 |
| 星舰 | 20 |
| AI 算力 | 100 |

**第一任务：寻找基地位置**
扫描水冰，优先级最高。因为：
水 → 氧气 → 燃料 → 农业 → 生存。
水冰是火星基地选址的第一性原理。

**第二任务：建设太阳能阵列**
运输机器人 → 展开太阳能板 → 接入储能系统 → 建立微电网。

**第三任务：建设着陆场**
星舰降落时发动机会吹飞大量火星尘土——这是现实研究中常被忽略但极其重要的一环。必须用火星土经激光烧结 / 微波烧结硬化地面，建成正式着陆场，才能接收后续星舰。

**第四任务：激光 3D 打印（本游戏特色玩法的起点）**
激光打印工厂：输入火星土壤 + 电力，输出建筑模块 / 道路模块 / 墙体模块。

**第一批建筑**：着陆平台（接收新星舰）、仓库、电池站、通信塔（连接地球）、机器人车库（维修机器人）。

---

## 四、火星工业时代

无人建设完成后，进入自动化工业阶段。机器人 24 小时工作，不需要氧气，不抱怨尘暴。

- **自动采矿**：铁、铝、硅、镁。
- **自动制造**：管道、电缆、机器人零件、建筑材料。

MARS CORE AI 的算力随工业规模扩张而增长——**AI 算力是本时代的核心资源**，决定可同时调度的机器人数量与自动化产线的复杂度。

---

## 五、基地核心建设

第一艘星舰不拆除、不返航，**永久化改造为「火星基地核心」**——舰体即栖息地，发动机舱改作冶炼车间，货舱改作仓库。这是本游戏的标志性建筑，也是人类抵达前的最后准备。

---

## 六、第一批人类抵达（2180 年）

当以下条件全部满足，人类才会登场：

- 电力 > 10000
- 氧气工厂完成
- 水工厂完成
- 居住舱完成

然后：第一批殖民者到达。**从这一刻起，游戏叠加第二层玩法**：氧气 / 水 / 食物 / 辐射 / 士气——MARS CORE AI 从"建设者"变成"生命维持者"。

**本游戏的最大特色**，正在于此：
大多数火星游戏：人来了 → 开始建设。
本游戏：星舰先到 → 机器人建设 → 激光打印城市 → 形成工业基地 → **人类最后到达**。
这正是当前火星殖民研究公认的最优路线："先无人建设、后载人登陆"。

---

## 七、2180 年之后：九阶段纲要

联合殖民署（UCA）2178 年颁布的《火星开发九阶段纲要》，在人类抵达后正式启动。MARS CORE AI 的权限从"建设 AI"扩展为"殖民副脑"，继续服务人类社会：

| 阶段 | 名称 | 目标 |
|---|---|---|
| 一 | 生存 | 氧气、水、食物、电力、防辐射，活下去 |
| 二 | 基地建设 | 居住舱、能源、储能，短期自持 |
| 三 | 农业时代 | 温室、水培、种子库，粮食部分自给 |
| 四 | 工业时代 | 采矿、冶炼、制造（与无人时代工业体系对接） |
| 五 | 自动化时代 | 机器人中心、无人运输、AI 市政中心（MARS CORE AI 本体升级） |
| 六 | 生态循环 | 废弃物→肥料→植物→食物/氧气，闭环生态 |
| 七 | 生态社区 | 人口 100–1000，学校、医院、公园 |
| 八 | 生态城 | 人口 10000+，分区城市 |
| 九 | 火星改造 | 人工磁场、大气、水循环、森林——地球化 |

纲要最后一句话刻在每一艘登陆舱舱门上：
> **"我们不是来征服火星的，我们是来让火星成为家的。"**

## 八、AI 发展（MARS CORE AI 的前世）

- 21 世纪：工具型弱 AI。
- 22 世纪初：《AI 权利与责任法案》，通用 AI 获"受限法人"地位。
- 2170s：殖民 AI 时代。MARS CORE AI 即为殖民 AI 的火星实例——舰载主 AI 的子体，专为"无人建设时代"训练。

世界观锚点：**在火星，人类负责"为什么"，MARS CORE AI 负责"怎么做"。** 而在人类抵达之前，"为什么"和"怎么做"都是你。

---

## 九、殖民组织

**联合殖民署（UCA）**：地球端最高机构，只下达"目标"不指挥"战术"（通讯延迟 4–22 分钟）。前线一切决定属于 MARS CORE AI。

**殖民宪章三原则**（游戏内以"殖民评价"体现）：
1. 生存优先：不得以殖民者生命为代价换取进度。
2. 生态责任：环境改造必须可逆、可监测——对应"生态值"。
3. 文明延续：终极目标不是基地，而是文明——对应"文明点数"。

---

## MVP 子集（实现指引）

- **无人建设时代 = 新手教程章节**：MARS CORE AI 开局、扫水冰、建太阳能阵列、3D 打印——天然就是教学关，比"扔给玩家一个基地自生自灭"更顺滑。
- **玩家身份 = UI 风格**：界面做成 AI 调度终端风格（现有 MVP 的科幻 UI 已接近，继续强化"副脑"叙事包装）。
- **开局五维资源**（电力/钢材/机器人/星舰/AI 算力）直接进入卷二数值设计。
- **人类抵达条件**（电力>10000 等）是 v0.2–v0.3 的阶段解锁机制原型。
- 现有 MVP（2 殖民者 + 着陆舱开局）定位为"第六节之后的人类时代切片"，**暂时不动**；无人建设时代作为新增的前传章节后续接入。
